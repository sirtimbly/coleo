What you’re looking at

  • These are reconstructed routing requests: state plus questions. The optional detail-selection request is not included.
  • Original snapshots are historical. Both versions use the prompts and action switches loaded when this report was built; the exact historical request was not saved.
  • Areas count JSON.stringify(...).length, the same character measure as the 100,000-character guard. These are neither UTF-8 bytes nor token counts.
  • JSON stored inside text fields can be explored further. Its escape characters count toward the area. “JSON syntax” accounts for keys and punctuation.
  • Common credential patterns are redacted in previews. Areas retain the source lengths; long previews are clipped only for display.

Fitted payload includes shared rubrics, short questions and iterative context reduction. Older activity is removed first; older discovery details become excerpts. Discovery identities, prior Brain actions and receipts remain. Hover contextSelection for the reduction counts. The 100k-character target is a local proxy; Jev also limits state plus the longest question to 32k tokens and the full request to 64k tokens.
