# Design: Dynamic Prompt Generation with Validation for Task Execution

## Overview

Create a sophisticated prompt generation system that:
1. Aggregates task context, discussions, and relevant notes
2. Validates prompt completeness using a reasoning model
3. Generates markdown-formatted prompts for OpenAI-compatible APIs
4. Supports iterative refinement with previous execution context
5. Rejects incomplete prompts with specific feedback
