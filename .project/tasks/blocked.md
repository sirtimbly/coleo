# Blocked Tasks

Tasks that are waiting on something before they can proceed.

---

*No blocked tasks currently.*

## How to Use This File

When a task becomes blocked, move it here with:

```markdown
### [TASK-XXX] Task Name
- **Blocked Since**: YYYY-MM-DD
- **Waiting On**: What it's waiting for
- **Original Estimate**: X hours
- **Assigned**: arm-name or Unassigned

**Description**: Brief description

**Blocker Details**: Explanation of what's blocking progress

**Unblock Criteria**: What needs to happen for this to be unblocked
```

When unblocked, move back to `current.md` or appropriate location.
