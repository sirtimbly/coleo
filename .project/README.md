# Octopai Project

**AI Agent Orchestrator using the Octopus Model**

A central brain coordinates AI "arms" that execute different task classifications (architect, development, QA). Arms are **not specialized**—they adapt based on task type. Human-agent communication happens via email (Maildir), and arms communicate via MCP (Model Context Protocol).

## Core Philosophy

See [requirements.md](./requirements.md) for the full philosophy:
- **Arms are not specialized** - Behavior by task classification
- **Progressive planning** - Tasks determined at runtime
- **Timeline UI** - Recent activity + next task, not CRUD backlog

## Getting Started

```bash
# Install dependencies
bun install

# Run the CLI
bun run dev

# Start brain (coordinates arms)
bun run brain run

# Start API server
bun run server
```

## Communication Flow

```
Human (Requirements/Decisions)
    ↓
Brain (Orchestrator)
    ├→ Architect Task → Plans & Tasks
    ├→ Development Task → Code & Discoveries
    └→ QA Task → Tests & Documentation
    ↓
Human (Status Reports & Notifications)
```
